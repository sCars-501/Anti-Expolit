🛡️ M4R7H Security

Lightweight Windows security tool focused on firewall protection and connection monitoring.

⚙️ Features

🧱 Windows Firewall configuration.
🔒 Restriction of incoming Remote Desktop (RDP) connections.
📡 Monitoring blocked connection logs.
🔍 Basic monitoring of suspicious process activity.
🟢 Simple console interface with status messages.

⚠️ Disclaimer

M4R7H Security is a defensive utility and does not guarantee protection against every connection or remote-access method.

⸻

🇸🇦 نبذة عن الأداة

أداة أمنية خفيفة لنظام Windows، تهدف إلى تعزيز إعدادات جدار الحماية ومراقبة الاتصالات والأنشطة المشبوهة.

المميزات:

🧱 ضبط إعدادات جدار الحماية.
🔒 تقييد اتصالات سطح المكتب البعيد (RDP).
📡 مراقبة سجلات الاتصالات المحظورة.
🔍 مراقبة أساسية لبعض أنشطة العمليات المشبوهة.
🟢 واجهة Console بسيطة تعرض حالة الحماية.

ملاحظة: الأداة وسيلة مساعدة للحماية، ولا تضمن منع جميع أنواع الاتصالات أو الوصول عن بُعد.
